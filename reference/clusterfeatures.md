# Cluster-specific average morphology measures

'clusterfeatures' generates heatmap visualization of average
cluster-specific morphology measures relative to other clusters

## Usage

``` r
clusterfeatures(data, featurestart, featureend)
```

## Arguments

- data:

  is your input data frame

- featurestart:

  is first column number of morphology measures

- featureend:

  is last column number of morphology measures
