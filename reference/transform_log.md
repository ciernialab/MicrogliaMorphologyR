# Transform data: Log scale

'transform_log' allows you to log scale your dataframe

## Usage

``` r
transform_log(data, x, start, end)
```

## Arguments

- data:

  is your input dataframe

- x:

  is the constant value you want to add (e.g., 0.1, 1)

- start:

  is first column number of morphology measures

- end:

  is last column number of morphology measures
