# Explore how experimental variables describe data

'plots_expvariable' colors points in pc space by experimental variables

## Usage

``` r
plots_expvariable(data, pc.xaxis, pc.yaxis)
```

## Arguments

- data:

  is your input data frame

- pc.xaxis:

  is the pc values you want on x-axis (e.g, PC1)

- pc.yaxis:

  is the pc values you want on y-axis (e.g., PC2)
