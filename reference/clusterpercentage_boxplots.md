# How do morphology cluster percentages vary across variables of interest?

'clusterpercentage_boxplots' generates boxplots that depict cluster
shifts with experimental variables of interest

## Usage

``` r
clusterpercentage_boxplots(data, ...)
```

## Arguments

- data:

  is your input data frame

- ...:

  list out your variables of interest without combining (e.g., Cohort,
  Sex, Treatment)
