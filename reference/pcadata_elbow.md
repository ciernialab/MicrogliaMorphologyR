# Dimensionality reduction using PCA and elbow/scree plot to get variance explained

'pcadata_elbow' allows you to perform PCA analysis and update your
dataframe

## Usage

``` r
pcadata_elbow(data, featurestart, featureend)
```

## Arguments

- data:

  is your input data frame

- featurestart:

  is first column number of morphology measures

- featureend:

  is last column number of morphology measures
